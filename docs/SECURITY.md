# Security Policy

## Supported versions

Only the latest release receives security fixes. Store installations update automatically; if you installed the extension from a ZIP file or the source code, please download the latest release.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or discussions.

Use private vulnerability reporting instead: open the **Security** tab of this repository and click **Report a vulnerability**.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it
- The extension version and the browser you used

## What to expect

This project is maintained by a single person, so responses are on a best-effort basis. Valid reports will be acknowledged, and a fix will be released as soon as it is ready.

## Scope

In scope:

- The extension code: the popup, the content script injected into Google Forms and the background service worker
- The handling of the Gemini API key stored in `chrome.storage.local`
- Anything that lets a web page or another extension read the key or control the extension

Out of scope:

- Incorrect or inappropriate answers generated by Gemini
- Vulnerabilities in Google Forms, the Gemini API or the browser itself, please report those to the vendor

## If your API key was exposed

The key stays in your browser and is sent only to Google. If you think it was exposed, revoke it in Google AI Studio and create a new one.
